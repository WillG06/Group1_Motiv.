# CS2TP Group 1 Car Rental Web App

A full stack car rental web application built with JavaScript, HTML, CSS, PHP and MySQL.
The system allows users to create accounts, browse cars and make bookings, while administrators manage vehicles and reservations.

## Main Functionality

* Car listings
* Booking system
* User registration and login
* Admin management panel

## Technology

Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
